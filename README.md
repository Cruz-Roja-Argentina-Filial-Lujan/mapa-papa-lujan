# Mapa de circulación de Luján

Visita del Papa León XIV · Luján, 2026.

La página consulta cada dos minutos el servicio público de lectura de la planilla. Solo devuelve elementos y medidas aprobados, verificados y con fuente pública. No permite editar la planilla.

Publicación: GitHub Pages, rama main, carpeta raíz. No requiere compilación.

Los datos se actualizan desde la planilla existente. Para modificar la interfaz, editar index.html o visor.js y subir los cambios al repositorio.
